# 🚀 JavaScript Mini Projects

> A collection of **beginner-friendly JavaScript mini projects** built to practice JavaScript fundamentals through real, small applications.

This repository contains projects that I am building **myself from scratch** while learning JavaScript.

The goal is simple:
